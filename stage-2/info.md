# Boolean nedir?

bool, yalnızca iki değer taşıyabilen bir veri türüdür:

```c
bool isStudent = true;
bool hasTicket = false;
```


# Karşılaştırma Operatörleri
| Operatör | Anlamı             | Örnek       |
| -------- | ------------------ | ----------- |
| `==`     | Eşittir            | `age == 18` |
| `!=`     | Eşit değildir      | `age != 18` |
| `>`      | Büyüktür           | `age > 18`  |
| `<`      | Küçüktür           | `age < 18`  |
| `>=`     | Büyük veya eşittir | `age >= 18` |
| `<=`     | Küçük veya eşittir | `age <= 18` |


# Mantıksal Operatörler
| Operatör | Anlamı            |

| `\|\|`   | Veya              |
| `!`      | Değil, tersini al |
